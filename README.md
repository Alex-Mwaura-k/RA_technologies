# RA Technologies

A modern, high-performance React web application built with Vite and Tailwind CSS. This project serves as the digital front door for RA Technologies, offering seamless user experiences, responsive design, and enterprise-grade infrastructure.

---

## 🚀 Features

*   **Responsive UI/UX:** Fully responsive design that scales perfectly from mobile devices to ultrawide desktop monitors.
*   **Global Notification System:** Features a highly customized, responsive global toast notification system (powered by `react-hot-toast`) that adapts its layout dynamically based on screen size.
*   **Modern Styling:** Built with Tailwind CSS, utilizing a professional dark-slate and tech-blue color palette.
*   **Interactive Forms:** Includes client-side validated contact and newsletter subscription forms.
*   **Optimized Build:** Bundled with Vite for lightning-fast hot module replacement (HMR) and optimized production builds.

---

## 🛠️ Tech Stack

*   **Framework:** [React](https://react.dev/) (via [Vite](https://vitejs.dev/))
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Routing:** [React Router](https://reactrouter.com/)
*   **Notifications:** [React Hot Toast](https://react-hot-toast.com/)
*   **Icons:** Heroicons / Custom SVG
